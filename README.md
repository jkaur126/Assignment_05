# Employee Directory & Branch Management API  
**Course:** Back-End Development – Red River College Polytech  
**Student:** Jaspreet Kaur 
**Assignment 5:** Advanced API Documentation and Security Enhancement  

## Overview  
This project is a **secure, well-documented RESTful API** created for **PiXELL-River Financial**.  
It manages both **employee records** and **branch locations**, with a focus on best practices in:  
- RESTful API structure using **Node.js + TypeScript + Express**  
- Data persistence with **Firebase Firestore**  
- Input validation using **Joi**  
- Comprehensive documentation through **OpenAPI 3 / Swagger UI**  
- Security enforcement using **Helmet.js** and **CORS**  
- Environment variable management via **dotenv**  
- Automated deployment of docs to **GitHub Pages**
